## Setup automation

Getting started with Snappin App takes less than a minute:

1. Create an [account](/signup)  
2. Click on **Add Accounts**  
3. Click **Connect** next to Gmail or Outlook  
4. Grant the required permissions  
5. Run a [retroactive search](/retroSearch) to pull past receipts  

That’s it — Snappin will start extracting receipts automatically in the background.
